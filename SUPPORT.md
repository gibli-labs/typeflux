# Support

## Where to ask

- **Bug reports and feature requests** — [GitHub issues](../../issues).
- **Questions and ideas** — GitHub Discussions (once enabled) or an issue
  with the `question` label.
- **Security reports** — never a public issue; see [SECURITY.md](SECURITY.md).

## What to include

State the package and version (`pip show typeflux`,
`npm ls @typeflux/temporal`), your Python/Node version, the SDK edition
(Python or TypeScript), and a minimal reproduction. For YAML-runtime issues,
attach the smallest workflow YAML that reproduces the behavior.

## Response expectations

This is a maintainer-run open-source project, not a commercial support
channel. Issues are triaged regularly; there is no guaranteed response SLA
outside the security policy.
